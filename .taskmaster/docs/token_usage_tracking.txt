# Overview
Implement a comprehensive **token usage tracking system** for the Image Generator Chat App. This system monitors and records API consumption (text prompts, image generation) per user, enabling billing, quota management, and cost analytics. Usage is calculated in real-time during API calls and stored in the database for reporting and enforcement.

---

# Goals (MVP)
- Track token usage from Gemini API responses
- Increment user token usage on each API call
- Store usage history for analytics and billing
- Enforce simple usage quotas (optional soft limits)
- Provide usage summary via API endpoint
- Log all usage events for monitoring
- Simple, performant implementation (no complex queue)

---

# Non-Goals (Explicitly Skipped)
- Complex billing/payment integration
- Usage-based pricing tiers
- Real-time usage dashboards (basic endpoint is fine)
- Historical usage analytics with time-series DB
- Multi-currency pricing
- Invoice generation
- Refund/credit system
- Advanced quota management (hard limits are post-MVP)

# Implementation Architecture

## Service Layer Structure

### 1. `usage.service.js` (NEW)
**Purpose:** Handle all token usage tracking logic

**Key Functions:**
```js
import lodash from 'lodash';
const { get, isNil } = lodash;

import { db } from '../db/drizzle.js';
import { users, usageLogs } from '../db/schema.js';
import { eq } from 'drizzle-orm';

/**
 * Increment user token usage
 * @param {string} userId - User UUID
 * @param {number} tokens - Number of tokens to add
 * @param {object} metadata - Optional usage metadata
 * @returns {Promise<object>} Updated user record
 */
export const incrementUserTokenUsage = async (userId, tokens, metadata = {}) => {
  if (isNil(userId) || tokens <= 0) {
    throw new Error('Invalid userId or token count');
  }

  // Update user token usage (atomic increment)
  const updatedUser = await db
    .update(users)
    .set({
      tokenUsage: sql`${users.tokenUsage} + ${tokens}`,
      updatedAt: new Date()
    })
    .where(eq(users.id, userId))
    .returning();

  const user = get(updatedUser, '[0]');
  if (isNil(user)) {
    throw new Error('User not found');
  }

  // Optionally log usage event
  if (get(metadata, 'logUsage', false)) {
    await logUsageEvent({
      userId,
      totalTokens: tokens,
      ...metadata
    });
  }

  return user;
};

/**
 * Log a usage event to usage_logs table
 * @param {object} usageData - Usage event data
 * @returns {Promise<object>} Created log record
 */
export const logUsageEvent = async (usageData) => {
  const log = await db.insert(usageLogs).values({
    userId: get(usageData, 'userId'),
    threadId: get(usageData, 'threadId'),
    messageId: get(usageData, 'messageId'),
    jobId: get(usageData, 'jobId'),
    operation: get(usageData, 'operation', 'unknown'),
    promptTokens: get(usageData, 'promptTokens', 0),
    completionTokens: get(usageData, 'completionTokens', 0),
    totalTokens: get(usageData, 'totalTokens'),
    estimatedCostUsd: get(usageData, 'estimatedCostUsd'),
    provider: get(usageData, 'provider', 'gemini'),
    model: get(usageData, 'model', 'gemini-2.5-flash'),
  }).returning();

  return get(log, '[0]');
};

/**
 * Get user usage summary
 * @param {string} userId - User UUID
 * @returns {Promise<object>} Usage summary
 */
export const getUserUsageSummary = async (userId) => {
  const user = await db
    .select()
    .from(users)
    .where(eq(users.id, userId))
    .limit(1);

  const userData = get(user, '[0]');
  if (isNil(userData)) {
    throw new Error('User not found');
  }

  const totalTokens = get(userData, 'tokenUsage', 0);
  const limit = TOKEN_USAGE.FREE_TIER_LIMIT;
  const remaining = Math.max(0, limit - totalTokens);
  const percentageUsed = (totalTokens / limit) * 100;

  // Estimate cost (rough calculation)
  // Gemini pricing: ~$0.01 per 1000 tokens (adjust as needed)
  const estimatedCostUsd = (totalTokens / 1000) * 0.01;

  return {
    totalTokens,
    limit,
    remaining,
    percentageUsed: Math.round(percentageUsed * 100) / 100,
    estimatedCostUsd: Math.round(estimatedCostUsd * 1000) / 1000
  };
};

/**
 * Get recent usage logs for a user
 * @param {string} userId - User UUID
 * @param {number} limit - Number of logs to return
 * @returns {Promise<array>} Array of usage log records
 */
export const getRecentUsageLogs = async (userId, limit = 50) => {
  const logs = await db
    .select()
    .from(usageLogs)
    .where(eq(usageLogs.userId, userId))
    .orderBy(desc(usageLogs.createdAt))
    .limit(limit);

  return logs;
};

/**
 * Check if user has exceeded quota
 * @param {string} userId - User UUID
 * @returns {Promise<boolean>} True if quota exceeded
 */
export const hasExceededQuota = async (userId) => {
  const summary = await getUserUsageSummary(userId);
  return get(summary, 'totalTokens', 0) >= TOKEN_USAGE.FREE_TIER_LIMIT;
};
```

# Integration with Image Generation Flow

## In `jobs.service.js` (processJob function):
```js
import { incrementUserTokenUsage } from './usage.service.js';

export const processJob = async (jobId) => {
  try {
    // 1. Update status to 'processing'
    await updateJobStatus(jobId, 'processing');

    // 2. Get job details
    const job = await getJobById(jobId);
    const prompt = get(job, 'parameters.prompt');
    const userId = get(job, 'message.thread.ownerId'); // Get user ID from thread

    // 3. Call Gemini API
    const result = await generateImage(prompt, {
      width: get(job, 'parameters.width', 1024),
      height: get(job, 'parameters.height', 1024)
    });

    // 4. Extract usage metadata from Gemini response
    const usageMetadata = get(result, 'usageMetadata', {});
    const totalTokens = get(usageMetadata, 'totalTokenCount', 0);
    const promptTokens = get(usageMetadata, 'promptTokenCount', 0);

    // 5. Track token usage
    if (totalTokens > 0) {
      await incrementUserTokenUsage(userId, totalTokens, {
        logUsage: true,
        operation: 'text2img',
        promptTokens,
        completionTokens: 0,
        provider: 'gemini',
        model: 'gemini-2.5-flash',
        threadId: get(job, 'message.threadId'),
        messageId: get(job, 'messageId'),
        jobId: get(job, 'id')
      });
    }

    // 6. Store image result
    const image = await db.insert(images).values({
      jobId: get(job, 'id'),
      url: get(result, 'imageUrl'),
      metadata: {
        width: get(result, 'width'),
        height: get(result, 'height'),
        mimeType: get(result, 'mimeType'),
        usageMetadata // Store for reference
      }
    }).returning();

    // 7. Update job status to 'succeeded'
    await updateJobStatus(jobId, 'succeeded', {
      parameters: {
        ...get(job, 'parameters'),
        usageMetadata
      }
    });

    // 8. Update assistant message
    await updateMessage(get(job, 'assistantMessageId'), {
      status: 'succeeded',
      content: `Generated image for: ${prompt}`
    });

  } catch (error) {
    // Handle errors...
  }
};
```

# Middleware (Optional - Quota Enforcement)

**File:** `src/middlewares/quotaCheck.js`
```js
import lodash from 'lodash';
const { get } = lodash;

import { hasExceededQuota } from '../services/usage.service.js';
import { errorResponse } from '../utils/response.js';

/**
 * Middleware to check if user has exceeded quota
 * Use on image generation endpoints only
 */
export const checkQuota = async (req, res, next) => {
  try {
    const userId = get(req, 'user.id');
    
    const exceeded = await hasExceededQuota(userId);
    
    if (exceeded) {
      return res.status(429).json(
        errorResponse('Token quota exceeded. Please upgrade your plan.', 429)
      );
    }
    
    next();
  } catch (error) {
    console.error('[Quota Check Error]', error);
    // Don't block on quota check errors - allow request through
    next();
  }
};
```

**Usage in routes:**
```js
import { checkQuota } from '../middlewares/quotaCheck.js';

// Apply to POST /threads/:threadId/messages route
router.post('/threads/:threadId/messages', 
  verifyToken, 
  checkQuota,  // Add quota check
  createMessage
);
```

# Cost Estimation (Rough Calculation)

**Gemini 2.5 Flash Pricing (as of June 2024):**
- Text-to-image: ~$0.01–$0.03 per image
- Text processing: ~$0.01 per 1000 tokens

**Example Calculation:**
- User generates 100 images/month
- Average prompt: 20 tokens/image
- Total tokens: 2000
- Text cost: $0.02
- Image cost: $1.00 (100 × $0.01)
- **Total: ~$1.02/month**
