```

- Image generation is the core MVP feature

```
Phase 4 (Core Image Gen) ← → Phase 5 (Basic Usage Tracking)

## 💰 Cost Considerations

### Gemini 2.5 Flash Pricing (as of June 2024)
- **Text-to-Image:** ~$0.01–$0.03 per image
- **Text Processing:** ~$0.01 per 1000 tokens

### Example Monthly Cost (100 users, 10 images each)
- Total images: 1,000
- Image generation: $10–$30/month
- Text processing: ~$1/month
- **Total: $11–$31/month** (API only)

### Budget Protection
- Set daily/monthly spending limits in Google Cloud
- Implement per-user quotas (e.g., 100 free images/month)
- Track usage in real-time
- Set up billing alerts

## 🎓 Key Learnings from Research

### Gemini 2.5 Flash Image API
- Uses Google Vertex AI platform
- OAuth 2.0 authentication via service account
- Pricing: ~$0.01–$0.03 per image
- Returns image URLs (not inline base64)
- Provides usage metadata for token tracking
- Rate limits: ~60-120 RPM per project
- Response includes usageMetadata object

### Best Practices Applied
- Service account authentication (secure)
- Async job processing (scalable)
- Proper error handling (robust)
- Token usage tracking (cost control)
- Test with mocked API (avoid costs)
- Environment-based configuration (flexible)
